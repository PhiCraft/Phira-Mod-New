【0】这份文档给谁看

  · 开服的人（主机侧）：一台 Windows PC，装「Phira 联机开服器」。
  · 玩的人（玩家侧）：iOS / Android 上的 Phira（本修改版），什么都不用装。

  当前进度很重要，先说清楚：
  · 开服器现在能做的：查公网 IPv6、更新动态域名、加防火墙规则，
    并且**内嵌了双人对战服务端**（开服就是它在跑）。
  · 标准联机（房间 / 选曲 / 聊天）：客户端自带，填地址即可用；
    但要用自己的服务器，得按【2.6】另外跑官方服务端（内嵌官方服务端是后面的事）。
  · 双人对战模式（BP 选曲 + 能量制干扰）：**服务端已就绪，客户端面板还没做**，
    所以现在还用手机玩不了，见下面那段。

  ===== 双人对战模式的进度 =====
  服务端（已内嵌进开服器）：
    · 开服后界面「对战房间」卡片实时显示：房间码 / 阶段 / 玩家 / 比分 / 曲池
    · 日志里能看到谁进房、谁 ban 了什么、谁对谁投了干扰、每局结算
    · 已经用真实进程验证过：连上、进房、求曲池交集、BP 轮次、ban 生效都正常
  客户端（还没做）：
    · 对战面板：房间码输入 / BP ban-pick 界面 / 能量条 / 干扰按钮
    · 四种干扰的画面效果：迷雾 / 抖线 / 噪点 / 压暗
  规则、协议、消息表：见 duel/README.md
  ==============================


【1】先看懂整体是怎么跑的

  玩家手机 ──(公网 IPv6)──▶ 你的 PC（开服器 + 服务端）
  同一个 WiFi 时 ──(内网 IPv4)──▶ 你的 PC

  两条关键事实：
  · 手机上要填的东西只有一个：「主机:端口」
    （比如 myphira.dynv6.net:12346 或 [240e:xxxx::1]:12346）
  · 客户端不需要任何修改：Phira 的「多人游戏服务器」地址本来就是可填的。


【2】开服（主机侧 · Windows PC）

  2.1 前置条件（不满足的话后面全是白折腾）

    a) 家宽有公网 IPv6
       在 PC 上开 PowerShell 跑：
         Get-NetIPAddress -AddressFamily IPv6 |
           Where-Object { $_.PrefixOrigin -eq 'RouterAdvertisement' -or $_.PrefixOrigin -eq 'Dhcp' }
       看到 240e: / 2408: / 2409: 开头的地址 = 有。只有 fe80:（链路本地）或没有 = 还没
       打通，先去光猫里把 IPv6 打开（电信 / 联通 / 移动的家宽现在大多都发 IPv6）。

    b) 光猫 / 路由器放行入站
       光猫里除了开 IPv6，还要允许外网主动连进来（有的叫「IPv6 防火墙」「端口过滤」，
       关掉或者给这个端口放行）。这一步只能你在光猫后台做，程序帮不了。
       注意：如果光猫是「路由模式」，还要确认它没有把 IPv6 转发关掉。

    c) 用高位端口，不要用 80 / 443（部分运营商封，且涉及备案）。默认 12346 就好。

  2.2 开服五步

    1) 右键 phira-launcher.exe →「以管理员身份运行」
       （加防火墙规则需要管理员权限；不加也行，但要自己去 Windows 防火墙里放行）
    2) 「设置」卡片：端口填 12346（官方服务器是 12345，错开避免混淆）
    3) 点「加防火墙规则」→ 自检里那一项应该变绿
    4) 点「启动服务」→ 状态灯变绿、日志出现「已监听端口 12346：IPv6 + IPv4」
    5) 看「链路自检」四项：
         公网 IPv6       绿 = 找到稳定地址了
         防火墙入站规则   绿 = 规则在
         端口监听        绿 = 服务起起来了
         动态域名        绿 = 域名已经指向当前地址（没配域名时是黄色，正常）

  2.3 把地址发出去

  · 「把这个填进 Phira 的联机服务器地址」那张卡片上就是最终地址，点一下即复制，
    或者点「显示二维码」让对方扫。
  · 没配域名时地址是裸 IPv6，长这样：[240e:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx]:12346
    方括号不能省。而且 IPv6 前缀会变（重启光猫、断线重连都可能变），
    变了就得重新发一次。

  2.4 强烈建议：配一个免费动态域名（dynv6）

    配了之后别人只要记住一个域名，你再也不用重新发地址。

    1) 打开 https://dynv6.net 注册（免费），创建一个域名，比如 myphira.dynv6.net
    2) 在该域名的详情页复制 token
    3) 开服器「设置」里填：域名 = myphira.dynv6.net，dynv6 token = 粘贴
    4) 勾上「每 3 分钟自动更新动态域名」（前缀变了会自动推）
    5) 点「立刻推 DNS」，自检里「动态域名」变绿就成了
    6) 之后分享的地址就是 myphira.dynv6.net:12346

  2.5 关服 / 开机自启

  · 关服：点「停止」，或者直接关窗口。程序一关，别人就连不上了
    （玩家那边会提示连接失败，这是正常的，不是 bug）。
  · 开机自启：给 exe 建个快捷方式放进
      shell:startup（运行框里输这个就能打开启动文件夹）
    并在目标后面加参数  --autostart ，启动后会自动开服。
  · 关掉窗口后想再开：重新双击 exe 即可，设置都存在 exe 旁边的 launcher.json 里。

  2.6 【现在就能真的联机】用官方服务端（可选，进阶）

    开服器内嵌游戏服务端是下一步的事。在那之前，如果你想现在就跟朋友打：
    开服器只当「地址 + 防火墙 + 自检」用，服务端另外跑官方的。

    1) 编译官方服务端（本机已有源码缓存，路径如下）：
         cd C:\Users\Administrator\.cargo\git\checkouts\phira-mp-369b632916014371\6967475
         cargo build --release -p phira-mp-server
    2) 开服器里【不要】点「启动服务」（否则会占用端口），
       只用「自检」「加防火墙规则」「立刻推 DNS」这几项。
    3) 跑官方服务端（端口要和开服器设置里的端口一致）：
         .\target\release\phira-mp-server.exe --port 12346
    4) 玩家按【3】填地址就能进房了。

    注意：官方服务端需要联网访问 phira 官方 API（phira.5wyxi.com）来验证登录、
    取谱面信息，所以主机必须能上外网。


【3】加入（玩家侧 · iOS / Android）

  3.1 先确认自己有 IPv6（这一步决定后面走哪条路）

    在手机浏览器打开 test-ipv6.com 或 ipv6-test.com：
    · 显示 240e: / 2408: / 2409: 开头的地址 → 有 IPv6，直接按 3.2 走。
    · 只有 IPv4 / 提示未检测到 IPv6 → 看 3.4。
    · 手机流量（4G/5G）一般都有公网 IPv6；家里的 WiFi 要看路由器有没有开。

    顺带说明：联机本身不费流量。只传触摸事件和分数，不传谱面音频，
    一局三分钟大概几百 KB 到几 MB。

  3.2 填服务器地址

    Phira（本修改版）里：
      设置 → 通用 →「多人游戏服务器」→ 填  主机:端口
    例如：
      myphira.dynv6.net:12346
      [240e:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx]:12346
      （IPv6 直连时方括号必须写）

    同时确认 设置 →「多人游戏」开关是打开的。

  3.3 进房间

    多人游戏面板里可以：连接、创建房间、加入房间（房间 ID ≤20 位字母 / 数字 / - _）、
    选择谱面、准备、房主开始、聊天、锁房、轮换房主、断线自动重连。
    需要先登录账号（没登录会提示「登录后才能进入多人游戏」）。

  3.4 如果玩家那边没有公网 IPv6，三条路

    A) Tailscale（对方装一次 App，免费）
       主机和玩家都装 Tailscale、登录同一账号组网，然后玩家填主机的
       100.x.x.x 地址。底层走 WireGuard，即使对方只有 IPv4 WiFi 也能通。
       缺点：国内连通性看运气（控制面和中继有时被墙）。

    B) 给主机补一条公网 IPv4（玩家零安装，最推荐）
       电信 / 联通的家宽经常打个电话就能要回公网 IPv4（移动多半是大内网）。
       有了之后在路由器上做个端口映射到你的 PC，玩家用最普通的 WiFi 就能直连，
       地址形如  家里的公网IP:12346。代价全在主机侧。

    C) 用一台有公网的小机器做中继
       免费方案见 Oracle Cloud Always Free；或者你 PC 本来就有公网 IPv4 就直接走 B。

    另外：如果玩家和你**在同一个 WiFi**（比如你家里两台设备），直接用内网 IPv4 就行，
    填 PC 的内网地址（形如 192.168.1.5:12346），什么都不用装。


【4】功能说明

  4.1 开服器（已实现）

    · 公网 IPv6 检测：按「存活时间最长」挑，自动避开隐私扩展的临时地址
      （临时地址几天就换，推上域名会失效）——这一点很关键，别手填。
    · 动态域名（dynv6）：手动「立刻推 DNS」+ 后台每 3 分钟自动检查前缀变化。
    · Windows 防火墙：加 / 查 / 删入站规则（规则名 Phira Launcher (TCP 端口)）。
    · 监听与观察：同时绑 IPv6 和 IPv4，「外部连接」会列出每个连进来的地址、
      时间、对方发了什么——用它判断「链路通没通」最直观。
    · 分享：大地址块点击即复制 + 二维码（手机扫码后可照着填）。
    · 界面：磨砂玻璃、深浅两套主题（右上角切换）、卡片和按钮有悬浮反馈。
    · 日志：界面上实时滚动，同时写一份 exe 旁边的 launcher.log（超过 2MB 自动重来）。
      出问题就把这个文件发出来，比描述现象有用得多。
    · 配置：exe 旁边的 launcher.json（绿色版，整个文件夹拷走就能用）。

  4.2 客户端联机功能（Phira 自带，本来就能用）

    只要「多人游戏服务器」填对，下面这些立刻可用：
    房间列表 / 创建房间 / 加入房间 / 选谱面 / 准备与开始 / 实时分数 /
    聊天 / 锁房 / 房主轮换 / 断线重连。

  4.3 还没做完的（规划中）

    · 内嵌游戏服务端：把官方 phira-mp-server（Apache-2.0）编进开服器，
      开了就不用手动跑第二个程序。
    · 干扰对战：两人同时打同一张谱面，靠 Perfect / Good 攒能量，
      花能量给对方投干扰（变速、迷雾、判定线摇晃、噪声），
      有冷却、开局 10 秒禁用、被干扰时屏幕会明确提示是谁放的。
    · BP 选曲：BO3 轮流 ban / pick，曲池 = 双方本地曲库的交集（不额外传谱面）。
    · 房间密码、人数上限、抗滥用（公网暴露的服务端会被扫）。

  4.4 明确不做 / 要注意的

    · 联机成绩不上传官方排行榜（跟着「上传成绩」开关走，默认关）。
    · 不提供公网中继服务：想跨网络又双方都没 IPv6，只能靠 Tailscale 或自备小机器。


【5】排查手册（照着顺序查，90% 的问题在前三步）

  Q1 玩家连不上（最常见）
    按顺序：
    1) 玩家自己有没有 IPv6？（3.1）没有就先解决这个，或者走 3.4
    2) 自检里「防火墙入站规则」是绿的吗？黄色就点「加防火墙规则」，
       还不变绿说明没以管理员身份运行
    3) 光猫放行入站了吗？（2.1 b）——连自检都绿但外面连不进来，八成卡在这
    4) 地址写对了吗？IPv6 要方括号：[240e:...]:12346
    5) 端口是不是被占了？日志会写「绑定失败」，换个端口再来
    6) 让玩家用手机关掉 WiFi 用流量，浏览器开
         http://[你的IPv6地址]:端口
       页面出现 PHIRA-LAUNCHER-TCP-TEST-OK = 链路通了，
       同时你的「外部连接」会多一条记录。这能一次排掉运营商 / 光猫的问题。

  Q2 自检里「公网 IPv6」一直是黄色
    · 只有 fe80: 开头的地址 → 光猫没开 IPv6
    · 完全没有 IPv6 → 运营商没给 / 光猫没拨上，重启光猫试试
    · 地址是 fd / fc 开头 → 那是内网地址（ULA），不是公网，用不了

  Q3 推 DNS 报错
    · "invalid token" → token 抄错了（注意别多空格）
    · "no change" → 地址没变，这是成功，不是错误
    · 一直失败 → 检查域名是不是在 dynv6 上建好了，以及本机能不能上外网

  Q4 端口被占用 / 绑定失败
    日志里会明说。换个端口（比如 12347），然后重新「加防火墙规则」。

  Q5 昨天还能连，今天不行
    多半是 IPv6 前缀变了：
    · 配了域名 → 开服器 3 分钟内会自动推，点「立刻推 DNS」可以马上推
    · 没配域名 → 只能重新把新地址发出去（这就是为什么要配域名）

  Q6 日志在哪
    exe 旁边的 launcher.log。界面里的「日志」卡片是同一份内容。

  Q7 界面白屏 / 点了没反应
    launcher.log 里会记前端报错（脚本出错会写成 [UI] 开头的行），
    把日志发出来定位最快。


【6】注意与风险

  · 防火墙只是放行【一个端口】的入站，不会把你的电脑暴露成公共服务器。
  · 主机必须开着：关机 / 关程序之后，玩家会提示连接失败，这是预期行为。
  · 家用宽带的服务条款一般不允许对外开服务器。小范围朋友之间玩没问题，
    真要公开给很多人用，请自己评估风险（用高位端口 + 非标准协议，实际被管的概率很低）。
  · 不要用 80 / 443 端口（备案问题 + 运营商封锁）。
  · 服务端需要访问 phira 官方 API（phira.5wyxi.com）验证登录、取谱面信息，
    完全断网的环境跑不了。
  · 官方服务端是 Apache-2.0 开源项目（TeamFlos/phira-mp），可自由使用和修改。

 快速版（贴给朋友看的那种）

  开服的人：
    1. 右键开服器 → 以管理员身份运行
    2. 点「加防火墙规则」→ 点「启动服务」
    3. 把卡片上的地址（或二维码）发出去

  玩的人：
    1. Phira 里 设置 → 多人游戏服务器 → 填那个地址
    2. 确认「多人游戏」开关打开、账号已登录
    3. 进多人游戏 → 加入房间

  连不上：
    先看玩的人有没有 IPv6（test-ipv6.com），再看光猫放行没放行入站。
