# Phira 联机开服器

把家里这台 Windows PC 变成 Phira 的联机服务器。**按需开机**：要打的时候双击，打完关掉。

> 面向使用者的完整说明（开服步骤 / 玩家怎么连 / 排查 / 功能清单）在
> [`联机使用教程.txt`](联机使用教程.txt)，发工具的时候把这个 txt 一起发出去。
> 本 README 是给改代码的人看的。

## 为什么是这个形态

- Phira 官方的 `phira-mp-server` 本来就是**监听 IPv6 `[::]` 的裸 TCP 服务**（不是 WebSocket），
  所以私有服务器不需要域名证书，家用宽带的公网 IPv6 直连就行。
- 客户端的联机服务器地址**本来就是可配置的**（设置 → 联机服务器地址，默认 `mp2.phira.cn:12345`，
  走 `ToSocketAddrs`），所以换成你自己的域名/地址**不需要改客户端代码**。
- 动态域名（dynv6）把「IPv6 前缀会变」这件事藏起来：别人只填一次域名，之后不用管。

## 现在到哪一步了

**milestone 1（本目录当前状态）：把链路验通**
- [x] 界面（Tauri + 静态 HTML/CSS/JS，**不需要 Node/pnpm**）
- [x] 公网 IPv6 检测（挑「存活时间最长」的那个 = 稳定地址，避开隐私扩展的临时地址）
- [x] dynv6 自动更新（手动刷新 + 每 3 分钟自动检查前缀变化）
- [x] Windows 防火墙入站规则（加 / 查 / 删，需要管理员权限）
- [x] 一个**最小 TCP 监听器**：手机上连过来，窗口里就会多一条连接记录
      —— 用它验证「光猫 → 防火墙 → DDNS → 外部能连进来」这条链路
- [ ] 真正的游戏服务端（下一步：vendor 官方 `phira-mp-server`，Apache-2.0，~1370 行）

> milestone 1 的验收方式：启动服务 → 手机上填 `域名:端口` 或用浏览器打开 `http://[IPv6]:端口` →
> 窗口的「外部连接」出现记录 = 链路通了。**这一步不通，后面写再多服务端逻辑也没用。**

## 怎么跑

```bat
cd launcher\src-tauri
cargo run            :: 开发
cargo build --release :: 出 exe（target\release\phira-launcher.exe）
```

防火墙规则那一步需要管理员权限；不加也能用，但要自己在「Windows Defender 防火墙 → 高级设置」
里放行该端口的入站，或者用管理员身份运行本程序。

## 别人怎么连

1. 在 [dynv6.net](https://dynv6.net) 免费注册一个域名（例如 `myphira.dynv6.net`），
   把「域名」和「token」填进设置。
2. 点「立刻推 DNS」，确认自检里「动态域名」变绿。
3. 把 `域名:端口`（或二维码）发给对方，他在 Phira 的
   **设置 → 联机服务器地址** 里填进去。
4. 对方需要有 IPv6（手机流量一般都有；只有 IPv4 的 WiFi 连不上 IPv6 主机）。

## 说明

- 服务端本身会拿玩家 token 去官方 API（`phira.5wyxi.com`）验证登录、取谱面信息，
  所以私人服务器**依赖官方 API 在线**，不是完全自给自足。
- 别用 80/443 这类端口（部分运营商封，且涉及备案），高位端口最稳。
- 家宽条款一般禁止对外开服务器，小范围朋友之间玩没问题，规模变大要自己评估。
